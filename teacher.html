Paste the codes your students send you — one per line, any mix of languages and any mix of Le Lexique and revision dossier codes. The page works out which is which. Everything is decoded in this browser: nothing is uploaded, and no server ever sees a student name.

Import the Forms responses

In Microsoft Forms choose Open in Excel, then Save As → CSV, and drop the file here. Every code in the sheet is picked up — column order, extra columns and comma-or-semicolon separators make no difference. Re-dropping a newer export later only adds what's new, so this is safe to repeat each half-term.

Drop the CSV here or click to choose a file · .csv, .txt, .tsv

Paste codes

Accepts LEXFR2. LEXFR1. LEXES2. LEXES1. DOSFR1. DOSES1. — one per line. Several codes from the same student over time are welcome: the newest is shown, with the change since the previous one.

Reading the tables

Seen — distinct items the student has met at least once, out of the whole list. Mastered — items answered correctly enough times to leave the review cycle. Leeches — items failed repeatedly; these are the ones worth teaching directly. Exam avg — mean of the in-app tests, with the number of tests in brackets. Done / Opened — dossier tiles marked finished, and tiles merely opened. Flagged hard — tiles the student marked difficult.
An amber row means seen is climbing but mastered is not — the student is browsing rather than learning, which is the pattern most worth catching early.

Codes carry aggregate statistics only — no answers, no free text. Decoded locally in this browser; no server, no upload. These are snapshots a student chose to send, not live monitoring. The roster is stored in this browser only: clearing site data, or opening the page on another machine, starts it empty — use the backup button to move it.
