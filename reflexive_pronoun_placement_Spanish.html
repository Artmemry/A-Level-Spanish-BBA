Colocación de Pronombres Reflexivos y de Objeto

A-Level Spanish (Edexcel) · Gramática · Duración recomendada: 40 min

Instrucciones: Completa cada frase colocando el pronombre en el lugar correcto, o elige la opción correcta. Usa el teclado de acentos si lo necesitas. Al terminar, pulsa «Comprobar» y descarga tus resultados.
Reglas clave:
  1. Con un solo verbo conjugado, el pronombre va delante: me levanto.
  2. Con verbo conjugado + infinitivo/gerundio, hay dos posiciones posibles: me quiero duchar / quiero ducharme.
  3. Con el imperativo afirmativo, el pronombre se pega al final: ¡Siéntate!. Con el imperativo negativo, va delante: ¡No te sientes!.
  4. Al pegar el pronombre a un infinitivo, gerundio o imperativo, la palabra suele necesitar una tilde para conservar el golpe de voz original (dándoselo, explicándoselo, levántate).
  5. Con dos pronombres, el indirecto le/les se convierte en se delante de un pronombre directo (lo, la, los, las): se lo, nunca le lo.

Ejercicio 1 · Un solo verbo conjugado (4 puntos)

Escribe la forma correcta con el pronombre en su lugar.

1. Yo (levantarse) ______ a las siete todos los días.

Pista
Un solo verbo conjugado → pronombre delante.

2. Ella (ducharse) ______ antes de desayunar.

Pista
3.ª persona singular: se + verbo.

3. Nosotros (acostarse) ______ tarde los fines de semana.

Pista
Nosotros: nos + verbo.

4. ¿A qué hora (despertarse – tú) ______?

Pista
Tú: te + verbo (con cambio e→ie: despiertas).

Ejercicio 2 · Verbo conjugado + infinitivo (4 puntos)

Reescribe usando los verbos indicados. Las dos posiciones del pronombre son correctas (sepáralas con «|» si escribes las dos, o escribe solo una).

5. (yo) querer + ducharse + antes de salir → escribe la frase completa.

Pista
«me quiero duchar» o «quiero ducharme», ambas correctas.

6. (mis hermanos) ir a + levantarse + temprano mañana → escribe la frase completa.

Pista
«se van a levantar» o «van a levantarse».

7. (tú, pregunta) poder + ayudarme + con esto → escribe la frase completa.

Pista
«puedes ayudarme» o «me puedes ayudar».

8. (ella) no + querer + quitarse + el abrigo → escribe la frase completa.

Pista
«no» va delante de todo el grupo verbal.

Ejercicio 3 · Verbo conjugado + gerundio (4 puntos)

Reescribe usando los verbos indicados. Recuerda la tilde al pegar el pronombre al gerundio.

9. (ella) estar + lavarse + las manos ahora mismo → escribe la frase completa.

Pista
«se está lavando» o «está lavándose» (con tilde).

10. (él) seguir + quejarse + constantemente → escribe la frase completa.

Pista
«se sigue quejando» o «sigue quejándose» (con tilde).

11. (nosotros) estar (imperfecto) + probarse + los trajes cuando llegaste → escribe la frase completa.

Pista
«nos estábamos probando» o «estábamos probándonos» (con tilde).

12. (yo) estar + explicarle + el ejercicio a mi compañero (combina le + lo = se lo) → escribe la frase completa.

Pista
«se lo estoy explicando» o «estoy explicándoselo» (con tilde).

Ejercicio 4 · Imperativo afirmativo (4 puntos)

Escribe la forma del imperativo afirmativo con el pronombre pegado (¡ojo con las tildes!).

13. ¡(Levantarse – tú) ______ ya!

Pista
levanta + te → necesita tilde: levántate.

14. ¡(Sentarse – usted) ______, por favor!

Pista
El imperativo de usted usa la forma del subjuntivo: siente + se.

15. ¡(Irse – nosotros) ______ de aquí!

Pista
Excepción: «vayámonos» pierde la -s → vámonos.

16. ¡(Callarse – vosotros) ______!

Pista
callad + os → la -d desaparece: callaos.

Ejercicio 5 · Imperativo negativo (3 puntos)

En el imperativo negativo, el pronombre va siempre delante y el verbo va en subjuntivo.

17. No ______ tan tarde. (levantarse – tú, negativo)

Pista
Negativo = pronombre delante + subjuntivo.

18. No ______ ahora, señora. (sentarse – usted, negativo)

Pista
Negativo (usted) = se + siente (subjuntivo).

19. No os ______ ahí. (quedarse – vosotros, negativo)

Pista
Negativo (vosotros) = os + quedéis (subjuntivo).

Ejercicio 6 · Doble pronombre: se lo / se la (4 puntos)

Sustituye los complementos por pronombres. Recuerda: le/les + lo/la/los/las → se lo/se la/se los/se las.

20. Le doy el libro a María. → ______ doy.

Pista
«le lo» no existe en español: le → se.

21. Compro los regalos a mis padres. → ______ compro.

Pista
les (a mis padres) + los (los regalos) → se los.

22. Ella le explica la regla a los alumnos. → Ella ______ explica.

Pista
le + la → se la.

23. Voy a dar el dinero a mi hermano. → Reescribe con pronombres: «Voy a ______» (dar + le + lo, con el pronombre unido al infinitivo).

Pista
dar + se + lo, pegado al infinitivo → necesita tilde: dárselo.

Desafío A* — Para ir más lejos
